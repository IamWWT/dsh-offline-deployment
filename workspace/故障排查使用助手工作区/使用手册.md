# 故障排查助手 · 使用手册

> 本工作区（`故障排查使用助手工作区`）是故障排查助手的默认工作区：会话在此打开时，自动加载本目录的 `故障排查SOP.md` 作为排查行为准则。
> 配套插件：`@dsh-tools/troubleshoot-assistant`（已预装、受保护不可卸载）。

## 1. 插件能做什么

| 能力 | 说明 |
|---|---|
| 数据源配置 | 设置页（设置 → 插件配置 → 故障排查助手卡片）配置 5 类数据源：指标 / 日志 / 调用链 / CMDB 变更历史 / 知识库（URL、认证、超时等） |
| 故障排查 | agent 按标准 RCA 流程调用查询工具，基于证据定位根因 |
| 证据补充 | 证据不足时自动（或按你要求）多源并行取证、扩大时间窗、换查询词 |
| 故障报告 | 生成结构化 Markdown 报告（现象/影响/时间线/证据/根因/处置/建议），可落盘 |
| 离线插件商店 | 设置 → 插件 → Plugin store 可离线浏览/搜索/安装（本地目录） |

## 2. 开工前：配置数据源

1. 打开 Web（http://127.0.0.1:9488），进入 **设置 → 插件配置**；
2. 找到「故障排查助手 · 数据源配置」卡片，按数据源类型展开分组填写并保存：
   - **URL**：仅 http/https，认证信息请勿写进 URL；
   - **认证方式**：无 / Bearer / Basic / 自定义请求头；
   - **Token/密码**：推荐填 `env:环境变量名`（机密不落盘）；直接填值也可（已存值不回显）；
   - **查询路径**：留空使用默认路径（指标 /api/v1/query_range、日志 /search、调用链 /api/v1/traces、CMDB /api/v1/changes、知识库 /api/v1/search）；
   - **说明**：填写该源的查询语法（如 PromQL 示例），帮助 agent 正确查询。
3. 也可以在 `data/settings.yaml` 直接编辑 `troubleshoot:` 段（热生效）。

## 3. 怎么提问（示例）

直接向 agent 提问即可，例如：

- **标准排查**：「API 服务从 10:00 起 5xx 增多，帮我排查一下」（agent 会自动确认时间窗 → 查变更 → 指标 → 链路 → 日志）；
- **指定时间窗**：「查一下 2026-08-20 09:30~10:30 支付服务的错误率与 CPU」；
- **带线索**：「订单超时，traceId abc123，查这条链路的调用链和错误日志」；
- **变更核查**：「这个故障窗口内 CMDB 有没有发布变更？」；
- **补充证据**：「证据还不够，把时间窗扩大到 2 小时，把日志关键词换成 connection refused 再查」；
- **多源取证**：「把指标、日志、调用链、变更在同一时间窗内都查一遍汇总给我」；
- **生成报告**：「把以上证据整理成一份故障报告，写到工作区」（报告落盘需在插件配置里设置 reportDir）。

## 4. agent 的排查流程（内置标准）

1. `troubleshoot_status` 确认可用数据源；
2. 澄清现象与时间窗；
3. `query_cmdb` 查变更 → `query_metrics` 看指标拐点 → `query_trace` 追调用链 → `query_logs` 深挖日志 → `query_knowledge` 检索历史经验；
4. 证据不足时 `troubleshoot_evidence` 多源取证 / 扩大窗口 / 换关键词；
5. `generate_fault_report` 生成报告。

## 5. 排查行为准则（SOP 提示词）——可按工作区自定义

- 默认准则文件：本工作区的 **`故障排查SOP.md`**（已内置「标准 / 禁止 / 原则 / 证据补充」四部分，可直接编辑）；
- **不同工作区可放各自的 `故障排查SOP.md`**，每个工作区的会话自动使用自己的准则；
- 工作区没有 SOP 文件时，回退到默认工作区的 `故障排查SOP.md`（全局基线）；再没有则用插件内置默认；
- 编辑保存后**立即生效**（每次对话的提示词组装都会重新读取）。

## 6. 常见问题

| 问题 | 说明 |
|---|---|
| 数据源未配置/未启用 | agent 会明确提示；去设置卡片启用并填 URL |
| 查询失败/超时 | 查看错误码（HTTP_ERROR/TIMEOUT/INVALID_URL 等）与提示；检查 URL 可达性、认证、超时配置 |
| 响应被截断 | 返回带 truncated 标记；可调大插件配置 maxResponseBytes |
| 卸载故障助手 | 该插件为预装保护插件，`dsh plugin remove` 会拒绝（见部署 MIGRATE.md） |
| 插件商店 | 设置 → 插件 → Plugin store（离线可用，本地目录） |

## 7. 附：工具清单

| 工具 | 作用 |
|---|---|
| `troubleshoot_status` | 列出已配置数据源与默认参数（无凭据） |
| `query_metrics` / `query_logs` / `query_trace` / `query_cmdb` / `query_knowledge` | 单源查询（时间窗/limit/额外参数） |
| `troubleshoot_evidence` | 多源并行取证（证据补充） |
| `generate_fault_report` | 生成结构化故障报告（可落盘） |
