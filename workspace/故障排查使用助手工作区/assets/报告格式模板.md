# 故障报告格式模板

> 本文件是报告组装模板：助手用 generate_fault_report 生成报告时，
> 按【报告格式开关】选择用通用模板还是企业专属格式。

## 报告格式开关
- 默认：通用模板（下方第一节）
- 若企业有专属格式：把模板贴入【企业专属格式】节，并将本行改为"企业专属"，
  助手将严格按该格式输出。

## 一、通用模板（默认）

### 1. 故障概述
- 一句话描述故障现象与影响（时间、范围、严重级别）

### 2. 影响范围
- 受影响的服务/业务/用户范围
- 影响时长与恢复时间点

### 3. 时间线
- 按时间排序：告警产生、用户反馈、变更操作、异常拐点、恢复动作、恢复确认

### 4. 证据清单
- 按数据源分类列出：
  · 指标（query_metrics）：查询条件 + 关键结果
  · 日志（query_logs）：检索表达式 + 关键日志片段
  · 调用链（query_trace）：traceId/服务 + 失败链路摘要
  · 变更（query_cmdb）：变更条目 + 时间
  · 知识库（query_knowledge）：命中经验 + 来源

### 5. 根因分析
- 根因结论（标注置信等级：已证实 / 高度疑似 / 待验证）
- 分析过程：现象 → 拐点 → 链路 → 日志 → 变更 → 根因的因果链

### 6. 处置与恢复
- 已执行的处置动作与效果
- 验证方法（如何确认故障已解决）

### 7. 后续建议
- 预防措施、监控补充、变更流程改进等（可执行、有责任人建议）

## 二、企业专属格式（按需启用）

> 在此粘贴企业要求的报告格式（例如工单模板、审计要求的字段清单、
> 管理层简报格式），助手将严格按其字段与顺序输出。

- 字段2：……
