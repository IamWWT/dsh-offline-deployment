## 二、每类组件的通用检查项（排查时按此顺序）

### 数据库 / 存储类
1. 连接数、连接池使用率（资源指标源）
2. 慢查询 / 错误日志（日志源，按组件关键字过滤）
3. 锁等待 / 死锁 / 阻塞会话（指标源或组件自身视图）
4. 容量：磁盘、表空间、备份状态（指标源）
5. 变更：DDL、参数调整、版本升级、迁移（CMDB 源）

### 缓存 / 消息队列类
1. 命中率 / 内存占用 / 淘汰与碎片（指标源）
2. 积压 / 消费延迟 / 消息失败（指标源 + 日志源）
3. 阻塞命令 / 慢操作（日志源）
4. 变更：配置、版本、扩容（CMDB 源）

### 网关 / 接入层类
1. 错误率 / 延迟分布 / 超时与重试（指标源 + 调用链源）
2. 连接拒绝 / DNS / 证书过期（日志源）
3. 上游依赖健康（调用链源）
4. 变更：路由、限流、证书、发布（CMDB 源）

### 容器 / 编排类
1. 资源：CPU / 内存 / 重启次数 / 节点压力（指标源）
2. 事件：OOM / 重启 / 驱逐 / 拉取失败（日志源）
3. 变更：镜像、配置、副本数、调度策略（CMDB 源）
